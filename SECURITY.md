# Security policy

Please **don't open a public issue** for a security problem.

Report it privately through GitHub instead: **Security → Advisories →
Report a vulnerability** on this repository. That includes a leaked
credential, a weakness in the pipeline or its cloud setup, or a way the
dashboard could be abused.

This is a solo portfolio project. Expect an acknowledgement within about a
week. There's no bug bounty.

All data this project processes is public GitHub activity from
[GH Archive](https://www.gharchive.org/). If you'd like your GitHub handle
removed from this project's tables, use the same private channel.

How the project handles credentials, data and disclosure:
[`docs/security.md`](docs/security.md).
